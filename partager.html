Partager un build

Choisis un build sauvegardé pour créer un lien autonome. La personne qui l’ouvre verra l’équipement, les stats, les aptitudes et le bonus de set sur une seule fiche.

À savoir : le lien contient une copie des choix du build pour pouvoir l’afficher sans connexion. Il ne contient pas ton identifiant Bungie ni les identifiants de tes objets. Toute personne qui reçoit le lien peut voir cette fiche.
